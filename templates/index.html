About The Project

This web application serves as the frontend interface for Crop Recommendation Using Soil & Weather Data Reference Paper Dataset.

The core engine is powered by a machine learning classification algorithm trained on a dataset of 2,200 agricultural records. It takes into account the NPK ratio, acidity, and regional climate data to recommend the most suitable crop out of 22 possible classifications.
